# Codex Bridge v1.0.0

Codex Bridge v1.0.0 为 Windows x64 提供本地的 ChatGPT ↔ Codex 上下文整理工作流。

## Highlights

- ChatGPT Web Capture 与 Native Messaging。
- Workspace-aware 的会话、Context Pack 和 Handoff 工作流。
- 只读 Codex 集成。
- 工作现场保存、预览、Restore、Quick Save、切换前自动保存和退出保护。
- 工作现场 ZIP Import / Export 与 SHA256 完整性校验。
- Dark / Light 主题和中文界面。

## Safety

- 交接前由用户确认草稿内容。
- 不自动发送或执行 Codex 任务。
- 不自动 Restore。
- 不执行 Git 写操作；Snapshot Restore 不修改项目文件。用户主动保存的 Notes、Context 导出和 Snapshot 会写入工作区。

## Known limitations

- Workspace affinity 会阻止把工作现场恢复到其它工作区。
- Codex 集成保持只读，不会替用户创建、发送或执行任务。
- 当前没有定时或后台 Snapshot timer；自动保存只在启用的工作区切换流程中触发，退出保护中的保存属于手动现场。
- Windows ZIP 尚未提供代码签名；请核对随包 SHA256，不要绕过系统安全限制。
